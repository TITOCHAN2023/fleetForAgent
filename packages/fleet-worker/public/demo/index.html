03 / Understand the route

RTC when available, WS fallback

Regular commands may take a direct RTC path. If that path cannot connect, they can use the existing WebSocket Hub path. Heartbeats and token revocation still use the control connection.

Direct-only file transfer is different. If direct setup fails, no relay carries the file.

04 / Keep AI participants separate

Two Fleet Agents, one machine

A Room can coordinate a developer and reviewer on the same device. Each task retains its assignee, session and frozen target device. The leader stores the Room ledger.

The machine service is the Fleet Sandbox plugin. AI runners are Fleet Agents. Sandbox is a product name, not an OS isolation guarantee.

Explore the plugin catalog, read permissions and retention, or follow setup for your own machines.

No demo action grants access to a real device. This example does not prove load capacity or platform compatibility.

03 / 确认传输路径

RTC 可用时直连，失败后走 WS

普通命令可以走 RTC 直连，连接失败后回到现有 WebSocket 中枢路径。心跳和 Token 撤销仍依赖控制连接。

direct-only 文件传输另有规则。建立不了直连就会失败，不会把文件改走中继。

04 / 区分 AI 参与者

两个 Fleet Agent 使用一台机器

Room 可以让开发者和审查者在同一台设备协作。每项任务保留执行者、会话和固定的目标设备。leader 保存 Room 记录。

机器侧程序叫 Fleet Sandbox 插件，AI 运行器叫 Fleet Agent。Sandbox 名称不承诺操作系统隔离。

继续看插件目录、了解权限与留存，或按接入说明连接自己的机器。

演示页面没有任何操作可以控制真实设备。这个示例不代表容量或平台兼容性测试。
