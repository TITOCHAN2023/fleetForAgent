Trust and data

Know what you are connecting

The Fleet Sandbox plugin runs commands with the privileges of its OS user. Start with ask for local confirmation. allow also authorizes plugins without another click. The name Sandbox does not mean a container or virtual machine.

The Hub is in the trust boundary

HTTPS/WSS encrypts transport. The Hub can see relayed command output, plugin payloads and Room messages. Direct-only file bytes travel between endpoints, while signaling and status still use the Hub. Do not treat all Fleet traffic as end-to-end encrypted against the Hub.

Your credentials and browser

The website uses a login cookie and local theme/language preferences. Tokens are shown once; save them privately and keep them out of shell history, screenshots and issue reports. A full account token carries broad authority within that account. Use a dedicated unprivileged user or VM for untrusted tasks.

This page describes repository behavior, not independently audited production settings. Hosted operational admins can see operational metadata and ban accounts without special machine-control rights. The operator still controls deployed code and infrastructure.

信任与数据

连接前先了解权限

Fleet Sandbox 插件使用所在系统用户的权限执行命令。先从需要本机确认的 ask 开始。allow 也会自动授权插件，不需要额外点击。Sandbox 名称不代表容器或虚拟机隔离。

中枢属于信任范围

HTTPS/WSS 加密传输链路，中枢仍能看到经过它的命令输出、插件消息和 Room 对话。direct-only 文件内容直接在端点间传输，信令与状态仍经过中枢。不能把所有 Fleet 流量说成对中枢端到端加密。

过期规则用于应用读取检查和定时清理，不保证立即物理擦除，也不覆盖基础设施日志、设备、插件和模型服务商的记录。重置 Token 会撤销凭据，不会清空全部数据或撤销已经完成的命令。

凭据与浏览器

网页使用登录 Cookie，并在本地保存主题和语言偏好。Token 明文只显示一次，请妥善保存，不要留在 shell 历史、截图和公开问题中。账号完整 Token 在账号内拥有广泛权限。不可信任务适合放在专用低权限用户或虚拟机。
